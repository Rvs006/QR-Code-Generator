
## WHAT TO CHANGE IN THE PROTOTYPE

The prototype has these simulated/placeholder items. Replace each one:

### 1. Replace PseudoQR component → Real QR generation
- Remove the `PseudoQR` component and `hashStr` function entirely
- Create `src/lib/qr-renderer.js` with an async `renderQR(payload, config)` function
- Use the `qrcode` npm package to generate real ISO/IEC 18004 QR codes on canvas
- Config controls: error correction level (L/M/Q/H), module size (px), quiet zone (modules)
- After QR generation, draw the asset tag text (bold, centered below QR) and folder path text (smaller, gray) on the same canvas
- Enable pixel-perfect mode: set `imageSmoothingEnabled = false` when config.pixelPerfect is true
- Store generated images as `{ dataURL, width, height }` per row in state
- Each gallery card, scan viewer, print preview, and config preview should display these real QR dataURLs via `<img src={dataURL} />`

### 2. Replace handleLoadDemo() → Real file upload
- Create `src/lib/file-parser.js` with a `parseFile(arrayBuffer)` function
- Use `XLSX.read(arrayBuffer, { type: 'array' })` to parse Excel files
- Extract 4 columns from the first sheet: Column A = mainFolder, B = subFolder, C = assetTag, D = payload
- Skip header row (row 1), trim whitespace, handle empty cells
- Wire drag-and-drop events on the drop zone (onDragOver, onDragLeave, onDrop)
- Wire a hidden `<input type="file" accept=".xlsx,.xls,.csv">` for click-to-browse
- Pass parsed rows through existing `validateRows()` function already in the prototype
- Remove MOCK_ROWS constant — use real parsed data
- Keep RECENT_FILES as mock for now (production would use localStorage)

### 3. Replace simulated generation → Real batch QR rendering
- In `handleGenerate()`, replace the `setInterval` simulation with an actual async loop
- For each selected row, call `renderQR(row.payload, config)` to generate real QR canvas
- Convert canvas to dataURL and store in a `generatedImages` state array
- Update progress bar with real progress (current/total)
- Add try/catch per row — failed rows should be logged but not stop the batch
- Use `await new Promise(r => setTimeout(r, 0))` between rows to keep UI responsive

### 4. Replace folder tree download → Real ZIP export
- Create `src/lib/zip-exporter.js` with async `exportToZip(generatedImages, config)` function
- Use `JSZip` to create ZIP, `FileSaver.saveAs()` to trigger download
- Build folder path per row: if both mainFolder + subFolder → `MainFolder/SubFolder/`, if one → that name, if neither → `Outputted QR Codes/`
- Filename: sanitized assetTag + `.png` based on config.format
- Extract base64 from dataURL, add to zip with `{ base64: true }`
- Name the ZIP: `Electracom_QR_Codes_YYYY-MM-DD.zip`

### 5. Replace print button → Real print
- Create `src/lib/print-labels.js` with `printLabels(generatedImages, config, printSelectedSet)` function
- Open `window.open('', '_blank')` and write a print-ready HTML document
- CSS: flex-wrap grid of labels, each sized to config.labelW × labelH mm using `@page` + mm units, `page-break-inside: avoid`
- Each label shows QR image via `<img src="dataURL" />` with asset tag below
- IMPORTANT: If printSelectedSet has entries, only print those indices. If empty, print all.
- Auto-trigger `window.print()` after 600ms delay for images to load

### 6. Replace verify simulation → Real QR decode
- Create `src/lib/qr-verifier.js` with async `verifyQR(imageDataURL, expectedPayload)` function
- Load the dataURL into an Image, draw onto a temp canvas, extract ImageData
- Use `jsQR(imageData.data, width, height)` to decode
- Compare decoded text to original source payload (exact string match)
- Return `{ passed: boolean, decoded: string, detail: string }`
- Detail: 'Payload matches source' on pass, or 'Decoded differs — expected X got Y' on fail

### 7. Add localStorage for theme
- On theme change, save to localStorage: `localStorage.setItem('ec-theme', dark ? 'dark' : 'light')`
- On app load, read from localStorage first, then fall back to system preference

### 8. Wire copy & save buttons
- Copy payload: `navigator.clipboard.writeText(payload)`
- Save image: convert canvas to blob → `saveAs(blob, 'assetTag.png')` using file-saver

### 9. Wire drag and drop on the upload zone
- Add `onDragOver`, `onDragLeave`, `onDrop` handlers to the drop zone div
- On drop, extract file and pass to file parser
- Show visual feedback (border color change) during drag

## ABOUT HOSTING

**Replit handles hosting automatically.** Once you deploy:
- Replit gives you a `.replit.app` URL  
- It's a static site (no server needed) — Replit's free tier works fine
- If you want a custom domain (e.g. `qr.electracom.com`), go to Replit Deployments → Custom Domain → add your DNS CNAME record

**No backend, no database, no environment variables needed.** The entire app runs in the browser.
